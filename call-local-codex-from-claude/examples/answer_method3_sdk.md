1. 英文译文

```latex
Catenary-free trams store energy onboard and replenish it during station dwell times. Figure~\ref{fig:architecture} illustrates the overall system architecture considered in this paper. The system comprises multiple tram lines operating within the same urban area, with their stations supplied by a common distribution network. When a tram dwells at a station, its pantograph connects to the station charging interface, which is connected to the urban distribution grid via a traction substation. For each station stop, the control center receives a request and returns a corresponding control instruction.
```
