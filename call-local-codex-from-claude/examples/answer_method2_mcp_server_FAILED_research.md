1. 英文译文

```latex
Catenary-free trams store energy onboard and replenish it during station dwell times. Figure~\ref{fig:architecture} depicts the system architecture investigated in this paper. Multiple tram lines operate within the same urban area, and their stations draw power from a shared distribution network. When a tram dwells at a station, its pantograph connects to the station's charging interface, which is linked to the urban distribution grid via a traction substation. For each station stop, the control center receives a request and returns a control command.
```
