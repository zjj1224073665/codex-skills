# Edit TeX Format for Different Journal

When reformatting a LaTeX manuscript for a target journal:

1. Download or locate the target journal's official LaTeX template before editing.
2. Compare the manuscript against the template and adapt the TeX structure, class, packages, bibliography style, figures, tables, and required front matter accordingly.
3. Check first-submission requirements, especially anonymous review, author information, acknowledgements, funding statements, declarations, line numbers, and supplementary-material rules.
4. If the current manuscript cannot satisfy an anonymity or submission-policy requirement without user input, stop and clearly tell the user what must be decided or changed.
5. After completing the task, delete temporary downloaded template files that are not needed long term.
